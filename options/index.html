Wii options

Open each one, click around, and tell me which you want. The others get deleted once you pick. Round 2 is the newer set, built to match the real Wii Menu more closely.

Round 1

  1. A. Only real channels
    Every channel is one the real Wii had (Disc, Mii, Photo, Wii Shop, Forecast, News, Internet, Everybody Votes), each opening into its own recreation of that channel.
  2. B. Fewer channels, real browser
    Six channels, mostly empty slots like a real family Wii. Everything opens inside a recreation of the Wii Internet Channel showing plain old-school web pages.
  3. C. Each channel its own app
    One channel per project, each a small full-screen app with its own look: a paper viewer for research, a fight card for OctaStats, a board for Chesque, the LED map photo full screen.
  4. Current version, for comparison.

Round 2

  1. D. Faithful menu
    As close to the real menu as possible: Disc, Mii, Photo, Wii Shop, Forecast, News, Everybody Votes and internet tiles. Each channel opens a simple screen with a title and big buttons.
  2. E. Through the Photo Channel
    Four channels. The Photo Channel holds everything: a cork board of photos and printed title cards, a full-screen viewer and a slideshow.
  3. F. Game discs
    Each project is a game with its own banner. Start shows a title screen with "Press A", then a small game menu.
  4. G. Message Board
    The mail button blinks. The Wii Message Board holds a dated letter for each job, paper and project.
  5. H. Just the menu
    Twelve tiles, one per thing, with slow banner motion. Start asks "Open this page?" and opens the real link. No content screens.
